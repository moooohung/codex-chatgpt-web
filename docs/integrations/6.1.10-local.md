upstream's tag still specifies 1.4.0, so this is a documented fork toolchain pin,
not a claim that upstream requires 1.4.2. Bun latest stable was checked as 1.4.3.

the entire matching Windows engine is built, installed and verified together.
Dependency automation remains enabled. No unrelated dependency refresh is included.

Verification includes both typechecks and audits, root/launcher offline suites,
inert browser/Electron fixtures for merged paths, complete runtime and renderer
builds, relocatable smoke, package/source integrity, and isolated install,
failure-injection and rollback checks. Executed counts/skips and installation
hashes belong in the package receipt; this document alone proves no live behavior.

quit, recorded active turns, full runtime/cache/engine readback and reservation
`phase: complete` with valid `healthyAt`. Profiles, credentials, Codex settings,
STS2 work files and unrelated work processes are not replacement targets.
No paid/Pro prompt or live login is required for this verification.
