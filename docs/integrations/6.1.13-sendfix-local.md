## Causes and changes

- **Send acceptance.** The local submission-recovery audit gave up after three 3-second checks,
  about 9 s, while upstream's Send stage budget is 180 s. Some failures happened before the first
  keypress, because benign DOM/draft normalization looked "ambiguous". The audit is retired; upstream's
  single physical activation and stage budget are used, and an ambiguous Send is still never replayed.
- **Compaction.** With `experimentalStagedCompaction` off, an oversized fresh compaction was sent whole
  and failed with `context_length_exceeded`. Now, when a direct fresh handoff cannot fit
  (`directCompactionFits`), the existing bounded lossless staged path is chosen before a browser opens.
  Retained handoffs and fitting fresh handoffs still follow upstream.
- **Unusual-activity cards.** New ChatGPT places product error cards inside the conversation group; the
  rejection reader excluded whole turn containers and missed them, so a blocked request waited 3 min for an
  ACK and was reported as a generic send error. Only real message prose is excluded now.
- **Error causes.** A stage timeout aborts with its own error instead of a bare "Aborted"; a multipart ACK
  timeout is reported as `multipart_acknowledgement_timeout`, non-retryable, stating the final prompt was not sent.
